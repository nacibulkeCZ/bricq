## About the Project 
The robot is designed around a protective rugby-ball-shaped outer cage so it can withstand impacts and potentially be thrown into an area before being used for observation. The current concept includes: 
- Quadruped locomotion
- 2 servos per leg
- Raspberry Pi Zero 2 W
- Live camera stream
- Wireless control from a phone or computer
- 3D-printed mechanical parts and protective structure
